# MKS Core

Задуман, как плагин для выноса функционала из темы сайта интернет-магазина. Сейчас пока — read-only REST API остатков WooCommerce для внешних партнёров. Разработан согласно пожеланию клиента.

**Версия:** 0.6.3  
**Требования:** WordPress 5.9+, PHP 7.4+, активный [WooCommerce](https://woocommerce.com/), активный [Advanced Custom Fields](https://www.advancedcustomfields.com/) (для полей «Баннеры в шапке»)

## Возможности

- REST endpoint остатков (только `GET`)
- Роль **МКС API Partner** (`mks_api_partner`) и capability `read_mks_api` (также у администратора)
- Авторизация через ключи WooCommerce REST API (Read)
- Настройки: URL endpoint’а, пагинация по умолчанию, атрибут и термин фильтра, порог складского остатка
- Поля группы «Баннеры в шапке» (позиция, цвет фона, изображение фона) объявлены в коде
- Таймер обратного отсчёта вместо баннера в шапке главной страницы и шорткод `[mks_countdown]`

## Зависимости

| Модуль | Требует |
|---|---|
| REST API остатков, настройки, бейджи категорий | WooCommerce |
| Поля «Баннеры в шапке» | Advanced Custom Fields |
| Таймер обратного отсчёта | — |

Без WooCommerce модули магазина не подключаются, без ACF — не регистрируется группа полей; в обоих случаях в админке выводится уведомление. Роль партнёра и опции создаются при активации плагина независимо от зависимостей.

## Установка

1. Скопируйте плагин в `wp-content/plugins/mks-core`
2. Активируйте WooCommerce и Advanced Custom Fields, затем MKS Core
3. **Настройки → MKS Core** — укажите атрибут и значение термина (без этого API вернёт 503)
4. Создайте пользователя с ролью партнёра (или используйте админа) и ключ WC REST API с правами Read

## Таймер обратного отсчёта

В записи типа `banner` (группа полей «Баннеры в шапке») есть поле **«Тип содержимого области»**:

- **Баннер** — обычный вывод, как раньше;
- **Таймер** — в этой области главной страницы выводится таймер до даты из поля **«Дата и время окончания акции»**.

Поля таймера:

| Поле | Назначение |
|---|---|
| Дата и время окончания акции | Момент окончания в часовом поясе сайта, формат `дд.мм.гггг чч:мм`. Не дальше 99 дней от текущего момента |
| Заголовок таймера | Текст над цифрами, по умолчанию «До конца акции осталось» |

Поведение:

- пустая, некорректная или уже прошедшая дата — выводится обычный баннер, пустого места не остаётся;
- таймер не кликабельный, ссылка баннера не используется;
- на открытой странице в момент окончания цифры обнуляются и остаются нулями до перезагрузки; после перезагрузки на месте таймера снова выводится баннер;
- после акции запись баннера нужно снять с публикации вручную, иначе вернётся баннер;
- переключатель действует только на позиции `up` / `down`.

Шорткод для обычного контента:

```
[mks_countdown until="2026-11-30 23:59:59" title="До конца акции осталось"]
```

`until` — дата в часовом поясе сайта, `title` необязателен. В содержимом записи `banner` шорткод не обрабатывается: для шапки используется переключатель.

Ограничения: при выключенном JS и закэшированной странице устаревшие цифры могут отдаваться до истечения кэша (на проде 48 ч). Стили и скрипт подключаются на главной странице и на записях, в содержимом которых есть шорткод; в ACF-полях, виджетах и шаблонах стили не подхватятся.

## Удаление

При удалении плагина снимаются роль партнёра, capability `read_mks_api` у администратора и option настроек. Ключи WooCommerce REST API в БД не трогаются.
